# zmk-config-CLine46

## トラックボール操作

- J+K は左クリック、K+L は右クリック、J+K+L は中クリック。DEFAULT と SCROLL で有効です。
- セミコロンは短押しで `;` (Shift 併用で `:`)、200 ms の長押しで SCROLL (レイヤー 4)。離すとカーソル移動に戻ります。
- SCROLL では、トラックボールの上下左右の動きを縦スクロールへ変換します。Shift を押している間は横スクロールです。
- `'` 長押しは FN (レイヤー 3)。FN ではカーソル移動のままです。
- オートマウスは初期設定で無効です。DYA Studio で以前有効にして保存した場合は、Studio 側でも無効にしてください。保存済みの移動速度を維持するため、設定の初期化は不要です。

## 速度設定

今回の操作変更では速度を変更していません。

- センサー: PMW3610、CPI 600。
- カーソル移動: `mouse_runtime_input_processor`。初期倍率は 1/1、DYA Studio で保存した設定がある場合はそちらが優先されます。
- スクロール倍率: `zip_scroll_scaler 1 16`。

Corcell は PAW3222 を使うため、同じ倍率でも同じ速度になるとは限りません。
